Pelagos

La gestion administrative et comptable des groupes d'entraînement, réunie dans une seule application — sur ordinateur et sur mobile.

Ce que nous faisons

GP Software développe Pelagos, un logiciel de gestion et de comptabilité pensé pour les entraîneurs autonomes qui encadrent des groupes. Suivi des membres, facturation, comptabilité courante : Pelagos rassemble les tâches administratives du métier dans un seul outil, pour que le temps se passe avec les groupes plutôt que dans les fichiers.

Pelagos — application de bureau

Mobile

Pelagos — application mobile
